御三家・セレビィ・交換進化キット … 別の クリスタル（日本版）の パッチに 御三家と セレビィの 入手方法・交換しなくても 進化できる を 入れる キット
================================================================================

「ポケットモンスター クリスタル 追加機能パッチ」Ver.1.5.0 から、つぎの 4つを 取りだした もの（ほかの 追加機能には たよって いない。4つは たがいにも たよって いないので、どれか だけでも 組める）。
入れる パッチに もう 入って いる ものは 組まない（下の「入って いる かの 見わけかた」）。

1. カントーの 御三家（src/starters.asm ＋ starters_crystal.asm）
   フシギダネ・ヒトカゲ・ゼニガメ（Lv10）を ピカチュウ版と 同じ 人・同じ 文で もらえる。
   ・フシギダネ：ハナダシティの こうかんの 話の 家の 女の人（いつでも。6, 3）
   ・ヒトカゲ：24ばんどうろ（ゴールデンボールブリッジの 北の はし）の 男の人（9, 1）
   ・ゼニガメ：クチバシティの ジュンサー（19, 15。オレンジバッジが いる。ない ときは 話だけ）
   もらう と「○○は フシギダネを てにいれた！」→ ニックネーム。手もちが いっぱいなら ボックスへ。もらった あとは「フシギダネ がんばってます？」など。
   ジュンサーの 絵は ピカチュウフルカラーの 絵（src/starters_jenny.inc。tools/starters_gen.py で 取り出した もの）。
2. セレビィ（src/legends.asm ＋ legends_crystal.asm）
   殿堂入りの あと、ウバメのもりの ほこらを しらべると「…おや？ ほこらの おくから なにかが とびだしてきた！」→ セレビィ（Lv30）と 戦う。
   1回だけ（つかまえても たおしても にげても いなくなる。まけた ときは また 会える）。殿堂入りの 前・会った あと・
   森が さわがしい（GSボールの イベント）ときは 元の ほこらの まま。
   legends_crystal.asm は 殿堂入りの あとの 伝説の 鳥（うずまきじま 地下2階 フリーザー・イワヤマトンネル 地下1階 サンダー・
   シロガネやま 2 ファイヤー、Lv50）も 入る。セレビィ だけに する ときは src/celebi_crystal.asm（legends_crystal.asm に
   DEF LG_NO_BIRDS EQU 1 を 足した もの）を かわりに 組む。
3. ジョウトの 御三家 3びき（src/johto3_crystal.asm。251匹そろう版の その 部分だけ）
   ウツギ はかせの けんきゅうじょで 1ぴき えらぶと、のこりの 2ひきも もらえる（えらんだ ポケモンだけ きのみを もつ）。
   ライバルの ポケモンは えらんだ 1ぴき（EVENT_GOT_〜_FROM_ELM）で きまるので 元の まま。
   すでに 1ぴき もらった セーブデータでは、ウツギ はかせに 話しかけると のこりの 2ひきを くれる（手もちも ボックスも いっぱいなら
   「ボックスを あけて また おいで」）。
4. 交換進化（src/tradeevo_crystal.asm。251匹そろう版の その 部分だけ）
   通信交換で 進化する 10ぴきが、交換しなくても 進化する。
     ニョロトノ … ニョロゾが Lv37 で 進化（元は おうじゃのしるし＋交換）
     キングドラ … シードラが Lv37 で 進化（元は りゅうのウロコ＋交換）
     ハガネール … イワークが Lv37 で 進化（元は メタルコート＋交換）
     ハッサム   … ストライクが Lv37 で 進化（元は メタルコート＋交換）
     ポリゴン2  … ポリゴンが Lv37 で 進化（元は アップグレード＋交換）
     フーディン・カイリキー・ゴローニャ・ゲンガー … ユンゲラー・ゴーリキー・ゴローン・ゴーストが Lv37 で 進化（元は 交換）
     ヤドキング … ヤドンに おうじゃのしるしを もたせて、Lv37 いじょうで レベルが あがると 進化（しるしは なくなる）。
                  もたせて いなければ 元の とおり Lv37 で ヤドラン。
   どうぐは いらない（Lv37 より 上の ポケモンは つぎに レベルが あがった とき 進化）。上の 9ひきは 進化の 表を レベルに かえるので
   交換では もう 進化しない。ヤドキングは しるしを もたせて 交換しても 進化する。しんかのいしの ときは 元の まま。
   おうじゃのしるしは クリスタルでは ヤドンのいど 地下2階の 男の人に もらえる・野生の ニョロゾ・ヤドランが もって いる ことが ある。

■ 入って いる かの 見わけかた（入れる パッチで たしかめて、入って いない ものだけ 組む）
  ・カントー御三家：ハナダの 家の 女の人・24ばんどうろの 男の人・クチバの ジュンサーが フシギダネ・ヒトカゲ・ゼニガメを くれるか。
  ・セレビィ：殿堂入りの あと ウバメのもりの ほこらで セレビィが 出るか（GSボールの イベント なしで）。
  ・伝説の 鳥：殿堂入りの あと うずまきじま 地下2階・イワヤマトンネル 地下1階・シロガネやま 2 に フリーザー・サンダー・ファイヤーが いるか。
    いれば セレビィは src/celebi_crystal.asm（鳥なし）で 組む。
  ・ジョウト御三家：ウツギ はかせの ところで 3びき もらえるか。
  ・交換進化：ユンゲラーなどが レベルで 進化するか（ROM では バンク$10 の 進化の 表の ユンゲラーが「03 ..」の ままなら 入って いない）。
    ほかの 方法（Lv や どうぐ で 進化する など）が もう 入って いれば 組まない。
  一部だけ 入って いる ときは、入って いない ものの asm だけを build.py に 書く。

■ 中身

  src/starters.asm・starters_crystal.asm・starters_texts.inc（文）・starters_jenny.inc（ジュンサーの 絵）
  src/johto3_crystal.asm

  src/charmap_jp.inc・src/safari/crystal_includes.asm・pokegold_events.asm（文字と スクリプトの 命令。命令の 番号は 日本版クリスタル＝英語版 金銀）
  pokecrystal/  pret/pokecrystal の constants/・macros/
  tools/overlap_check.py（ぶつかりを 調べる）・tools/starters_gen.py（ジュンサーの 絵と 文を ピカチュウフルカラーの ROM から 作る。ふつうは いらない）

■ 組みかた（rgbds 1.0.4 の rgbasm・rgblink・rgbfix を PATH に）
  1. 入れたい ROM を base.gbc として この フォルダに 置く
  2. python3 build.py feat.gbc                    … 4つ ぜんぶ（セレビィは 伝説の 鳥つき）
     python3 build.py feat.gbc src/celebi_crystal.asm src/starters_crystal.asm src/johto3_crystal.asm src/tradeevo_crystal.asm   … セレビィは 鳥なし
     （どれか だけ なら、その asm だけを 書く）
  3. python3 mkips.py base.gbc feat.gbc feat.ips
  元の クリスタルに 4つ ぜんぶ 組むと CRC32 1A521E2F、鳥なしで 472FCA7D。交換進化 だけは 90E2A035。
  （交換進化を のぞいた 3つは BDBBFCFA、鳥なしで 52D33D66）

■ 書きかえる 所・使う 所（元の クリスタル）
  カントー御三家：
    ハナダの 家（7-3）$1c:$5bf6〜$5cac・24ばんどうろ（7-15）$28:$6bab〜$6e07 を バンク$77 の 同じ 場所に、クチバシティ（12-3）$27:$6e7f〜$7240 を
    バンク$78 に 写し、人を 1人 足した イベントの 表（$77:$7400・$7500、$78:$7400）を 作って、MapAttributes（バンク$25）の スクリプトの
    バンク・場所を かえる。本体 $77:$6200、ジュンサーの 絵 $77:$6800。
    ジュンサーの 絵の 番号：使われて いない SPRITE_OLD_LINK_RECEPTIONIST（$58）の OverworldSprites（$05:$4727 ＋ 6×（$58−1））を かえる
    （種類は STANDING_SPRITE の まま。クリスタルは $58 が 外の 絵の 表に もとから ある ので 表は かえない）。
    しるし：$d836 の ビット4〜6。オレンジバッジは wKantoBadges（$d84b）の ビット2。
  セレビィ（と 伝説の 鳥）：
    ほこらの bg_event の スクリプトの 場所（$19:$64ce）を $19:$7ff8 の farsjump に。本体 $77:$6000。
    鳥：うずまきじま 地下2階（$1c:$4a5f〜）・イワヤマトンネル 地下1階（$1f:$6e75〜）・シロガネやま 2（$1c:$4b5a〜）を バンク$77 の 同じ 場所に 写し、
    MAPCALLBACK_OBJECTS で wMapObjects（$d711）の 4番に 鳥を 書く。
    しるし：$d836 の ビット0〜3。
  ジョウト御三家：
    ElmsLab の 3つの givepoke（$1b:$62b7・$62f9・$6335）を farscall（バンク$6e:$4000〜）に、ウツギ はかせの スクリプトの 場所
    （$1b:$7302、元 $61f5）を $1b:$7ff8 の farsjump（$6e:$6e00〜）に。しるし：$d837 の ビット4〜6。
  交換進化（どれも バンク$10）：
    進化の 表（EVOLVE_TRADE「03, どうぐ, しゅるい」の 03・どうぐ を「01, 37」に）：
      $6e2f ニョロゾ・$6e5d ユンゲラー・$6ea5 ゴーリキー・$6f5e ゴローン・$70f6 ゴースト・$7125 イワーク・$7317 シードラ・$739a ストライク・$74bd ポリゴン

  モバイルの 処理が 使う）。

■ 別の パッチに 入れる とき
  1. 元の クリスタルを base.gbc に して 組み、python3 tools/overlap_check.py 元.gbc ほかのパッチ.gbc feat.gbc で ぶつかりを 調べる。
  2. 写す マップ（ハナダの 家・24ばんどうろ・クチバシティ・うずまきじま 地下2階・イワヤマトンネル 地下1階・シロガネやま 2）を ほかの パッチが
     かえて いる ときは、写しを その パッチの ROM から 作る（INCBIN "base.gbc" で 読むので、ほかの パッチの ROM を base.gbc に すれば
     その 中身が 写る。ただし 〜_crystal.asm の 場所〔ST_〜_START・EVENTS・END、LG_〜_START・EVENTS・END〕が ずれて いれば かえる）。
     人を 足す 場所（ST_〜_X・Y）や 鳥の 番号（LG_〜_SLOT ＝ その マップの 人の 数＋1）も その パッチの マップで たしかめる。
  3. 交換進化：ほかの パッチが 進化の 表や EvolveAfterBattle を かえて いる・ずらして いる ときは、その ROM で さがしなおす
     （進化の 表は「03 ?? ss」、.trade は「fa dc c2 a7 ca」で はじまる 所）。ED_TradeCheck は バンク$10 の 空きに ないと だめ（call で よぶ）。
  4. 空きの 場所（バンク$77・$78・$6e、$19:$7ff8・$1b:$7ff8・$10:$7fa0）や RAM（$d836・$d837）を ほかの パッチが 使って いれば、DEF を べつの 空きに うつす。
  5. ElmsLab・ウツギ はかせ・ウバメのもりの ほこらの スクリプトを ほかの パッチが かえて いれば、givepoke の 場所（5バイト「2d ss 05 ad 00」）・
     はかせの object_event の スクリプトの 場所・ほこらの bg_event の 場所を その ROM で さがしなおす。
  6. ほかの パッチを 当てた ROM を base.gbc に して 組む。

■ たしかめる こと
  ・カントー御三家：3人から もらえる（ニックネーム・手もち いっぱいで ボックス・もらった あとの 文・ゼニガメは オレンジバッジ なしで 話だけ）。
    3つの マップの もとの 人・看板が 元の まま。
  ・セレビィ：殿堂入りの 前は 元の 文、あとは セレビィ Lv30 と 戦う、にげた あとは 元の 文だけ、まけた ときは また 会える。
    （鳥つきなら 3つの 場所で 鳥と 戦える）
  ・ジョウト御三家：新しく はじめて 1ぴき えらぶ → 3びき。すでに 1ぴき もらった セーブで ウツギ はかせに 話す → のこりの 2ひき、
    もう一度 話すと 元の 話。ライバルの ポケモンが えらんだ 1ぴきに あわせて 元の まま。
  ・交換進化：ユンゲラー・ゴースト・イワーク・ストライク などが Lv36 → 37 で 進化する（Lv36 までは しない）。
    ヤドン：しるしを もたせて Lv37 → ヤドキング（しるしが なくなる）、もたせないで ヤドラン。しんかのいし・なつき進化は 元の まま。
  ・レポートを 書いて 読みなおしても しるしが のこる（もう もらえない・もう 出ない）。
  このキットでは、追加機能パッチの 中で 御三家・セレビィの 3つとも、と、セレビィ だけ（鳥なし）・ジョウト御三家 だけ・交換進化 だけ
  （251匹そろう版の ほかの 部分なし。フーディン・ハッサム Lv37、ヤドキング／ヤドラン、Lv31 では 進化しない）でも 動くことを 確かめた。
  4つ いっしょに 組んだ ROM は、交換進化が かえる バンク$10 と ほかの 3つが かえる 所が かさならず、それぞれ 単独で 組んだ ものと 同じ バイトに なる ことを 確かめた。
